# NAVIO 交互反馈

本轮保留现有页面结构，统一地图、导航、设备、账号入口和设置页的反馈。
不改导航控制器、BLE 协议、原生地图手势或登录逻辑。

## 触觉

`services/interaction_haptics.dart` 管理三档反馈：切换 Tab、选择地图样式用
selection；搜索、地图按钮、账号入口、连接设备用 light；开始和结束导航用
medium impact。它们表示操作已被点击，不代表联网、配对或路线请求已成功。

只从按钮被实际激活的回调触发。按下后滑走、滚动、取消触摸和禁用按钮不触发。
80 ms 内的重复触感会合并，但不吞掉操作回调。触觉不受支持或调用失败时，
导航和按钮操作照常执行。不为 GPS 更新、自动重连或后台同步增加震动。
iOS 的 CupertinoSwitch 已有原生触觉，不再叠加一次。

## 动效与状态

`ui/navio_feedback.dart` 的 `NavioPressEffect` 只监听指针，不参加手势竞争，
不自己执行点击，也不包住整个地图。按下缩到 97%，松开恢复；滚动或取消会复位。
仍由原来的按钮处理语义、焦点、键盘和点击。

- 按下 90 ms，恢复 180 ms，状态过渡 220 ms；系统关闭动画时不缩放、过渡为零。
- Tab 选中图标轻微放大。切换保留 IndexedStack 和原地图实例，不给地图添加淡入重建。
- 设备连上后边框变蓝、图标交叉淡入，背景光晕为静态，不持续呼吸。
- 设备页的连接按钮在连接中禁用。首页连接卡片在搜索、连接、等待配对时可点击
  取消，调用手动断开接口停止扫描和自动重连；取消尚未完成时防止重复触发。
- 地图样式保存时显示进度，保存期间阻止竞争写入；点已选样式不重写、不震动。
- 路线规划中 Start 按钮显示规划状态并禁用，ETA 的加载与结果轻量切换。
- 小地图按钮的最小点击区域为 44×44 逻辑像素；不缩小原生按钮的点击范围。

## 验证

新增 `interaction_haptics_test.dart`、`navio_feedback_test.dart` 和
`interaction_controls_test.dart`，检查分档与限频、失败降级、取消与滚动、
禁用与减弱动态效果、键盘与无障碍语义、地图实例保留、样式保存竞争。
设备展示拆分有独立的 `device_header_test.dart`。

实际触感强弱和流畅度仍需要 iPhone 验证。本轮不自动构建或安装到手机。
验收时检查：普通点击、开始/结束导航、连续滚动、切换 Tab、快速选地图样式，
以及在系统中打开“减弱动态效果”后的行为。

## 首页 Connect 的强化反馈

仅首页完整连接卡片按下缩至 94%，松开以 easeOutBack 在 240 ms 内恢复；
其他按钮保留原来的轻按反馈。可取消状态显示关闭图标，沿用本地化 Cancel 标签。

`widgets/tap_ripple.dart` 用局部点击坐标作为圆心：450 ms 内从零扩散到
按钮宽度 2.4 倍的直径，半径为宽度 1.2 倍；初始透明度 0.28，线性淡至 0。
扩散半径用 easeOutCubic，绘制裁剪在圆角内，关闭 InkWell 默认水波和高亮，
避免叠加透明度。独立 RepaintBoundary 和 IgnorePointer 不影响原按钮点击。
滑动超出触摸阈值或触摸取消时清除波纹，减弱动态效果时不播放。

`tap_ripple_test.dart` 验证坐标、参数和生命周期；`connection_card_cancel_test.dart`
用模拟连接端口验证三个忙碌阶段的取消、防重复点击和恢复待连接状态。
实际蓝牙阶段的取消仍需在真机体验；本次复用已有 disconnect，不更改无线协议。

## 地图选点弹出

点击地图选点时，底部卡片以底边中心为锚点，从 78% 放大，轻微超过原尺寸后
回落到 100%，总时长 420 ms。透明度在前 30% 的时间内从 0.35 升至 1。
动画组件 `widgets/map_selection_pop.dart` 放在底部滚动区域外，避免回弹被裁切。

首页只有明确的地图选点操作才递增动画事件序号。路线预览返回、ETA 或 GPS
更新不重播；连续选点重启同一个动画，不堆叠旧卡片。导航中和减弱动态效果
模式直接显示，原生地图不在缩放/淡入范围内，实例和按钮状态保持。

## 首页地图布局比例

竖屏右侧按钮组位于安全区下方约可用高度的 20%，起点限制在 108–180 点，按钮间距 64 点；连接卡片收起时仅上移 24 点，不再挤到顶部。横屏保留紧凑的右侧工具栏，底部面板在左侧。按钮点击区域仍不小于 44 点。

目的地面板缩减边距、搜索行留白和字号，保留搜索、偏好、途经点与开始导航操作；底部距离屏幕安全区 16 点。宽屏面板最大宽度 480 点，避免铺满地图。路线取景下方预留同步缩减到 200 点。
